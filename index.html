Como funciona

Um benchmark meme. Em vez de calcular pontos em um jogo, ele enche a tela de vacas até alguma coisa na máquina chegar no limite.

  1. Entra uma vacaCada vaca é uma janelinha que atravessa a tela, muge no meio e sai pelo outro lado.
  2. A cada 2 segundos as vacas dobram1, 2, 4, 8, 16… Cada vaca é independente das outras.
  3. Até algum componente chegar no limiteO componente que bateu o limite é o gargalo, e esse é o nível máximo. Existe uma trava de segurança para não passar de um número máximo de vacas.
  4. Segura a carga por 4 segundosNesse tempo ele mede o FPS com tudo no talo.
  5. Sai o MooScoreA pontuação junta quantas vacas a máquina aguentou com o quão fluido tudo continuou.
MooScore = vacas no pico × FPS médio sob carga Exemplo: 100 vacas × 60 FPS = MooScore 6000.

Duas versões

A original é um programa de desktop em Python, que roda local na tua máquina. A web já está no ar e roda direto no navegador, sem instalar nada.

Python · PyQt5

Original

É a versão de verdade. Cada vaca é o cow.py rodando como um processo separado: uma janela sem borda, transparente e sempre por cima, com o contador de vacas no canto da tela.

Lê o uso real de CPU e RAM com psutil e o da GPU pela nvidia-smi (só placas NVIDIA).

Baixar Como rodar
HTML · JavaScript

Web

Cada vaca é uma janela real do navegador, movida com window.moveTo, com o mesmo vaca.png e o mesmo mugido. A página do teste é o fundo, com grid e a marca na parede.

Navegador não mostra o uso de CPU, RAM e GPU. Por isso o limite vem da queda de FPS, do lag e da memória JS. No fim dá pra baixar o JSON.

Download

O código do BenchMoo está no GitHub. Baixa pra rodar a versão original (Python) na tua máquina, ou pra dar uma olhada em como tudo funciona.

GitHub · pixelcatBR

pixelcatBR/BenchMoo

Abre o repositório e clica em Code → Download ZIP, ou clona com o git.

Baixar no GitHub

Ou clona pelo terminal

git clone https://github.com/pixelcatBR/BenchMoo.git
cd BenchMoo
  • Só precisa baixar pra usar a versão original.
  • A versão web não precisa de download: é só abrir o teste no navegador.

Como rodar

Original (local)

pip install PyQt5 psutil
python3 main.py
  • Baixa o código na seção Download e roda de dentro da pasta.
  • Deixa o cow.py, o vaca.png e o vaca_mugido.mp3 na mesma pasta do programa.
  • Para sair: botão "Parar e sair", fechar a janela ou Ctrl+C no terminal.
  • Sem nvidia-smi, ele mede só CPU e RAM.

Web

  • Já está no ar no GitHub Pages, é só abrir:
https://pixelcatBR.github.io/BenchMoo/teste.html
  • Não precisa instalar nada nem rodar servidor.
  • Libera os pop-ups para o site, senão só a primeira vaca abre.
  • No Linux com tiling ou Wayland, as janelas das vacas precisam ser flutuantes para andar. A própria página do teste explica como.
